# Accounting-of-events

Система учитывает следующие типы мероприятий: лекции, семинары, конференции, конкурсы, спортивные соревнования, встречи с работодателями.  
**Цель системы:** оптимизировать процессы учёта и организации мероприятий в университете.

## Что отслеживается

- **Мероприятие:** название, дата, время, место, организатор, максимальное количество участников.
- **Статус мероприятия:** запланировано / проведено / отменено.
- **Запись студентов** на мероприятия.
- **Посещаемость** участников.
- **Пользователи** системы.

## Пользователи и их права

### Организатор

Организатор может:

- создавать мероприятия;
- редактировать и удалять собственные мероприятия;
- отменять мероприятие;
- просматривать список записавшихся студентов;
- отмечать посещаемость (статус «пришёл» / «не пришёл»);
- просматривать отчёт по мероприятию (количество записавшихся, количество пришедших, процент посещаемости).

### Студент

Студент может:

- просматривать список доступных мероприятий;
- фильтровать мероприятия по дате или типу;
- записываться на мероприятие (с проверкой наличия свободных мест);
- отменять собственную запись;
- просматривать свои текущие и прошлые записи на мероприятия.

## Основные функции системы

- **Авторизация и регистрация:** вход по логину и паролю; роль (организатор/студент) определяется при регистрации и подтверждается администратором.
- **Управление мероприятиями:** создание, редактирование и удаление мероприятий (доступно только для организаторов).
- **Запись на мероприятие:** студент нажимает кнопку «Записаться», система автоматически проверяет наличие свободных мест.
- **Отмена записи:** студент может отменить свою запись на мероприятие.
- **Просмотр участников:** организатор видит список студентов, записавшихся на мероприятие.
- **Отметка посещаемости:** организатор фиксирует факт посещения мероприятия каждым участником.
- **Формирование отчётов:** система предоставляет организатору отчёт с данными о количестве записавшихся участников, количестве фактически пришедших и проценте посещаемости.

## Хранимые данные

### Пользователи

- `id`;
- ФИО;
- логин;
- пароль;
- роль (организатор / студент).

### Мероприятия

- `id`;
- название;
- описание;
- дата;
- время;
- максимальное количество участников;
- статус;
- `id` организатора.

### Записи на мероприятия

- `id`;
- `id` студента;
- `id` мероприятия;
- статус записи (записан / отменён);
- статус посещения (был / не был).
